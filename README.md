# khwarshi_dictionary_database
Khwarshi dictionary database, parsed from (Dzhidalaev, Magomedova, Khalilov 2022)

Актуальная версия словаря с правильными индексами находится в файле "full_khwarshi_draft_fixed_ipa". Сейчас готова разметка meaning_ru, в процессе исправление примеров и проблем распознавания (носовые, ударения). Также в meaning_ru находятся два дополнительных тега - delete me (для строчек, которые из финальной версии нужно удалить, сейчас они оставлены для сохранения индексации) и ? (те случаи, где по даннным словаря невозможно установить корректный meaning_ru, т.к. идёт циклическая ссылка или возможная опечатка).
